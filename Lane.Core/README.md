# Lane.Core

The core of [Lane](https://github.com/Church-of-Lane/lane): identity, messages, the session pump, the turn pipeline, prompts, and the model, tool and memory abstractions.

It depends on nothing provider-shaped. Model adapters live in [Lane.Providers](https://www.nuget.org/packages/Lane.Providers).

Documentation: https://lane-bot.readthedocs.io
