# Lane.Nodes.Protocol

The wire protocol between [Lane](https://github.com/Church-of-Lane/lane) and its nodes: the message types, the JSON settings, and the payloads nodes sign.

To write a node, use [Lane.Node.Sdk](https://www.nuget.org/packages/Lane.Node.Sdk) instead, which speaks this protocol for you.

Documentation: https://lane-bot.readthedocs.io/en/latest/nodes/
