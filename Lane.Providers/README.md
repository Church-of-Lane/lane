# Lane.Providers

Model adapters for [Lane](https://github.com/Church-of-Lane/lane):

- **Anthropic**, through the official `Anthropic` SDK
- **OpenAI-compatible** endpoints, such as OpenRouter and DeepSeek
- **TypeSafe System One**

Each implements the model abstraction from [Lane.Core](https://www.nuget.org/packages/Lane.Core).

Documentation: https://lane-bot.readthedocs.io
